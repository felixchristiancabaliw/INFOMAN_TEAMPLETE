## Database Setup (Without Docker)

1. Create a project in [Supabase](https://supabase.com).
2. Open the **SQL Editor** (`>_`) in your Supabase dashboard[cite: 2].
3. Copy and run the code in `01_migration.sql` to build the database schema.
4. Copy and run the code in `02_seed.sql` to insert seed data.
